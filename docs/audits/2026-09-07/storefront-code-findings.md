## 1. P0 — Predictable confirmation URLs expose order/customer data
Evidence: [app/(store)/checkout/thank-you/page.tsx:32](</Users/shanakajayakody/eastcoastlabs/storefront/app/(store)/checkout/thank-you/page.tsx:32>) queries the service-role DB using only the supplied `order` parameter, filtering by `order_number` at line 40; line 92 renders customer email, lines 124–138 render items and total, line 103 reveals `/pay/{order.id}`.
