# Compliance Guardrails — ecl-conversion

**This document is the compliance reference for every module in the ecl-conversion plugin. It is non-negotiable.**

## The Core Rule

This store sells **research-use-only peptides**. The "research use only" positioning is the legal shield. Every piece of copy, hook, review, email, and offer generated by this plugin must preserve it.

## Banned Language (never use in any output)

| Banned | Why | Use Instead |
|--------|-----|-------------|
| "month supply" | Implies human dosing schedule | "vial", "pack", "restock" |
| dosage / dosing | Implies human consumption | "quantity", "amount" |
| "take" | Implies human consumption | "order", "purchase", "stock" |
| "results" | Implies therapeutic effect | "outcomes" (in research context only) |
| weight-loss / healing / anti-aging | Health benefit claims | Never. Period. |
| before/after imagery | Implies therapeutic transformation | Never. |
| "unlock", "elevate", "seamless" | Marketing fluff that triggers scam detection | Specific, factual claims |
| "trusted by X" (fabricated) | Fake social proof | Real numbers only ("4,183 orders shipped since 2024") |
| Permanent fake "was/now" | Fake compare-at anchor | Real N× single-price anchors only |
| Countdown timers / "sale ends today" | Fake scarcity | Real stock status only |

## Required Framing

- **Quantities**: always "vials" or "packs" — never "month supply" or "supply duration"
- **Purchases**: frame as "lab restocking" ("keep your research supplied", "restock")
- **Reviews**: moderate out any that describe human use or effects (see below)
- **Emails**: replenishment reminders reference supply levels, never usage effects
- **Disclaimer**: every PDP, email, and new surface includes "research use only" language

## How Each Module Enforces Compliance

### Stock Status (Phase 0.3)
- Uses factual inventory data only — no "limited stock!" urgency
- Status text: "In stock", "Made to order", "Out of stock" — no scarcity manipulation

### COA Module (Phase 1.2)
- Presents independent lab data factually
- Never claims therapeutic benefit from purity
- Footer: "Independently tested. Every result published. If it doesn't pass, it doesn't ship."

### Guarantee Block (Phase 1.3)
- Covers purity verification only (not efficacy)
- "If any independent lab test shows your batch below X% purity, we refund or replace"
- Does not promise product "works" or produces any outcome

### Tier Cards (Phase 2.2)
- Labels: "1 vial", "3 vials", "6 vials" — never "1/3/6 month supply"
- Per-vial pricing: "$44.83 per vial" — never "per month" or "per day"
- 6-pack perk: "Includes FREE Bacteriostatic Water + FREE Express Post" — logistics, not efficacy

### Bac Water Attach (Phase 2.3)
- Copy: "required for reconstitution" — laboratory preparation, not administration
- Never describes how to "use" or "inject" or "administer"

### Restock Program (Phase 3)
- Named "Restock Program" — not "refill" (which implies medication cycles)
- Toggle copy: "Restock automatically & save 10%" — delivery scheduling, not dosing
- Cadence: "delivery every 12 weeks" — never "3 month supply"
- Pre-renewal email: "Your restock ships soon" — never "your supply is running out"

### Checkout Trust (Phase 1.5)
- Describes payment security and billing discretion
- Never promises product efficacy or legal status

### Emails (Phase 5)
- All Klaviyo flows reference: dispatch speed, packaging, COA verification, restocking
- Post-purchase "verify your COA" email is a trust-builder — no efficacy claims
- Replenishment timing is based on order interval (supply logistics), not usage schedule

### Reviews Moderation
- **Hard rule**: never publish reviews describing human use, effects, or results
- **Approve only**: service (dispatch speed), logistics (packaging/discretion), testing (COA verification, independent lab testing)
- Judge.me moderation queue documentation includes this rule
- This rule is documented in the plugin's settings page help text

## Review Moderation Rule (hard, documented)

> Never publish reviews that describe human use, effects, dosing, or therapeutic outcomes.
> Approve reviews about: dispatch speed, packaging/discretion, COA verification, independent lab testing.
> This rule must be documented in the moderation notes so it survives staff changes.

## Maintenance

- Any new copy added to the plugin or site must be checked against this document
- The `wp ecl scan-consistency` command does NOT check compliance — a human must review new copy
- When adding new products, ensure descriptions follow the de-AI rules in the plan (§1.6)
